Connect to GitHub

This panel edits your site by committing to its repository. It needs a personal access token with permission to write to that one repository.

Create one at GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Under Repository access pick only this repository, and under Permissions set Contents: Read and write. Nothing else is needed.

The token is kept in this browser only and is sent nowhere except github.com. Leave this unticked on a shared computer.
